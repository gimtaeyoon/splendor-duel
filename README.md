# 💎 스플렌더 대결 — 웹판

두 사람이 각자의 휴대폰·PC 브라우저로 즐기는 **스플렌더 대결(Splendor Duel)** 입니다.
같은 와이파이가 아니어도, 서로 멀리 떨어져 있어도 **링크 하나로** 같이 할 수 있어요.

- **설치·가입 없이 플레이**: 게임 주소를 열고 방을 만든 뒤 링크를 카톡으로 보내면 끝
- **PC를 켜 둘 필요 없음**: 두 폰이 무료 공용 중계 서버 세 곳을 통해 바로 연결됩니다
- **끊겨도 이어서**: 폰을 껐다 켜거나 새로고침해도 같은 방으로 돌아오면 그대로 이어집니다
- **원작 규칙 그대로**: 카드 67장·왕실 카드 4장의 수치를 여러 자료로 교차 확인했고, 특권·보드 채우기·조커·왕관 같은 세부 규칙도 공식 규칙서대로 동작합니다
- 한 기기로 둘이 하기, 봇과 연습하기(쉬움/보통), 규칙 안내, 첫 게임 안내, 이모티콘 반응, 내 차례 알림(진동·소리·탭 제목)

---

## 1. 폰으로 언제든 하려면 — GitHub Pages에 올리기 (추천, 한 번만 하면 됨)

GitHub Pages는 무료 웹호스팅이에요. 한 번 올려 두면 `https://아이디.github.io/splendor-duel/` 같은 고정 주소가 생기고, 두 사람 모두 그 주소로 들어가면 됩니다.

1. [github.com](https://github.com) 에 가입(무료)하고 로그인합니다.
2. 오른쪽 위 **＋ → New repository** 를 누릅니다.
   - Repository name: `splendor-duel`
   - **Public** 선택 → **Create repository**
3. 새 저장소 화면에서 **uploading an existing file** 링크를 누릅니다.
4. 이 폴더에서 아래 항목들을 끌어다 놓습니다. (`css`·`js`·`assets` 는 폴더째 끌어다 놓으면 돼요)
   - `index.html`, `manifest.webmanifest`
   - `css` 폴더, `js` 폴더, `assets` 폴더
   - `node_modules`, `.tunnel` 폴더는 올리지 마세요. (크기만 크고 게임에는 필요 없어요)
   - `.claude` 폴더도 올릴 필요 없어요. 개발 도구 설정이라 게임과는 상관없어요.
   - `docs`, `tests`, `tools`, `README.md`, `start.bat`, `package.json` 은 올려도 되고 안 올려도 됩니다.
5. 아래쪽 **Commit changes** 를 누릅니다.
6. 저장소의 **Settings → Pages** 로 가서
   - Source: **Deploy from a branch**
   - Branch: **main** / **/(root)** → **Save**
7. 1~2분 뒤 같은 화면 위쪽에 주소가 나타납니다. 그 주소를 폰에서 열어 보세요.
   - 폰 브라우저 메뉴의 **홈 화면에 추가** 를 누르면 앱처럼 아이콘으로 열 수 있어요.

> 게임을 고친 뒤에는 바뀐 파일만 3~5번처럼 다시 올리면 됩니다.

## 2. 지금 바로 PC에서 해 보기

1. [Node.js](https://nodejs.org) LTS 버전이 설치되어 있어야 합니다. (아발론·초성퀴즈를 돌려 봤다면 이미 있어요)
2. 이 폴더의 **`start.bat`** 을 더블클릭합니다. 브라우저가 열리고 서버 창에 주소가 표시됩니다.
3. 서버 창에 `✓ 인터넷 초대 링크가 잘 열려요` 가 나오면, 그다음부터 대기실의 초대 링크가 자동으로 그 인터넷 주소로 만들어져요. 멀리 있는 상대도 그 링크로 들어올 수 있어요.
   - 이 방법은 **PC와 서버 창이 켜져 있는 동안만** 페이지가 열립니다. 오래 쓰려면 1번(GitHub Pages)을 추천해요.
   - 인터넷 주소는 Cloudflare 무료 임시 주소(가입 불필요)로 만듭니다. 이 폴더나 옆의 다른 게임 폴더(아발론·초성퀴즈 등)의 `.tunnel` 안에 `cloudflared.exe` 가 있으면 그것을 쓰고, 없으면 Windows에 들어 있는 ssh로 localhost.run 주소를 만들어요.
   - 같은 와이파이라면 서버 창의 `같은 와이파이에서: http://192.168…` 주소로도 들어올 수 있어요.

`index.html` 을 더블클릭해서 PC 브라우저로 바로 열어도 게임이 동작합니다. (온라인 대전 포함) 다만 이때 초대 링크는 이 컴퓨터에서만 열리니, 상대에게는 **방 코드 6글자**를 알려 주세요.

## 3. 같이 하는 방법

1. 한 사람이 이름을 적고 **온라인 방 만들기** 를 누릅니다.
2. 대기실에 나온 **링크 보내기** (또는 **복사**) 로 상대에게 링크를 보냅니다. 방 코드 6글자를 불러 줘도 돼요. (상대는 홈의 "또는 받은 코드로 참가" 칸에 적고 **참가**)
3. 상대가 링크를 열면 **초대받았어요!** 화면이 나와요. 이름을 적고 **참가하기** (또는 키보드의 Enter) 를 누르면 게임이 자동으로 시작됩니다. 선 플레이어는 무작위이고, 후 플레이어가 특권 1개를 받고 시작해요.
   - 전에 이름을 적어 둔 폰이면 링크를 열자마자 바로 방에 들어가요.
4. 중간에 나갔다가 다시 들어오면 홈 화면의 **이어하기** 에서 방을 고르면 됩니다. 방마다 "내 차례 / 상대 차례" 가 표시돼요. 받은 링크를 다시 열어도 돼요.
5. 게임이 끝나면 **다시 하기** 로 같은 방에서 한 판 더! (진 사람이 먼저 시작)

처음 하는 게임에서는 내 처음 세 차례 동안 아래 막대 위에 **처음 안내** 가 한 줄 나와요. 누르면 규칙의 그 부분이 열리고, **안내 끄기** 를 누르면 다시 나오지 않아요.

**다른 폰으로 바꿔서 이어 하려면**: 새 폰에서 같은 링크를 열고 **같은 이름**으로 들어가세요. "이 방에는 이미 두 사람이 있어요" 화면에서 **내 자리예요 · 이어받기** → **이어받기** 를 누르면 됩니다. 원래 폰은 자동으로 관전으로 바뀌어요.
(이름이 다르면 꺼진 자리에만 **○○ 자리 이어받기** 가 보이는데, 꺼진 기기는 1분쯤 지나야 오프라인으로 바뀌어요.) 구경만 하려면 **관전하기**.

### 수를 두면 아래 막대에 뜨는 작은 표시

내가 수를 두면 화면 아래 행동 막대 안에 작은 표시가 잠깐 떠요. (방 만들기·자리 잡기처럼 수가 아닌 것에는 안 떠요)

| 표시 | 뜻 |
|---|---|
| 보내는 중… | 중계 서버로 보내고 있어요 |
| 보냄 | 중계 서버가 받았어요. 상대 폰이 꺼져 있어도 서버에 남아 있다가, 상대가 들어오면 바로 받아요 |
| 상대가 받았어요 | 상대 폰이 내 수를 받았어요 |
| 아직 못 보냈어요 · 다시 연결하는 중 | 8초 넘게 서버에 못 보냈어요. 다시 연결되면 저절로 보내요. 오래가면 와이파이·데이터를 확인하고 새로고침해 보세요 |
| 상대에게 아직 전달되지 않았어요 | 서버에는 있는데, 접속해 있는 상대 폰이 10초 넘게 못 받고 있어요. 보통 상대 폰이 잠깐 멈춘 거라 기다리면 돼요 |

- 내 차례인데 아래 막대에 **다시 연결하는 중… 잠시 후 이어서 둘 수 있어요** 가 보이면, 최신 게임 상태를 확인하는 중이에요. 몇 초 뒤 버튼이 다시 나와요. (옛 화면 위에서 잘못 두지 않게 잠깐 막아 둬요)
- **상대가 먼저 둔 수가 있어서 내 수가 취소됐어요** 가 뜨면, 연결이 끊긴 사이 둘 다 수를 둔 경우예요. 화면이 최신 상태로 바뀌어 있으니 확인하고 다시 두면 돼요.

## 4. 연결 방식에 대해

- 두 기기는 무료 공용 MQTT 중계 서버 세 곳(EMQX, Coreflux, HiveMQ — 가입 불필요)에 **처음부터 모두 동시에** 연결해서 게임 상태를 주고받습니다. 한두 곳이 불안정해도 남은 곳으로 이어져요.
- 게임 상태는 중계 서버와 각자의 브라우저에 저장되므로, 둘 다 잠시 나갔다 와도 이어서 할 수 있습니다.
- 공용 서버라서 **방 코드를 알거나 서버를 둘러보는 사람은 게임을 볼 수 있고, 마음먹으면 망가뜨릴 수도 있어요.** 둘이서 가볍게 즐기는 용도예요. 보내는 개인 정보는 이름(별명)과 무작위 기기 번호뿐입니다.
- 화면 위에 알림 줄이 보이면:
  - "인터넷 연결이 끊겼어요" / "중계 서버와 연결이 끊겼어요. 다시 연결하는 중이에요…" → 잠시 기다리면 자동으로 다시 연결됩니다. 오래 지속되면 새로고침해 보세요.
  - "○○님이 잠시 자리를 비웠어요" → 상대 폰이 30초 넘게 꺼져 있어요. 돌아오면 바로 이어져요.
- 회사·학교 와이파이처럼 443 포트만 열린 곳에서는 세 곳 중 Coreflux 하나만 쓸 수 있어서, 그곳이 불안정하면 연결이 안 될 수 있어요. 그럴 땐 휴대폰 데이터로 바꿔 보세요.

## 5. 자주 묻는 질문

- **상대 화면에 내 행동이 안 보여요** → 아래 막대의 표시가 "보냄" 이었다면 서버에는 잘 올라가 있어요. 상대가 다시 들어오는 순간 최신 상태를 받습니다. 그래도 이상하면 둘 다 새로고침해 보세요.
- **카톡 인앱 브라우저에서 이상해요** → 초대 화면의 **다른 브라우저로 열기** 를 누르거나, 오른쪽 위 메뉴에서 **다른 브라우저로 열기**(크롬/사파리)를 눌러 주세요. 카톡 안의 브라우저는 저장 공간이 따로라 나중에 "이어하기" 가 안 될 수 있어요.
- **내 차례 알림** → 화면을 켜 두면 진동·소리·탭 제목(● 내 차례)으로 알려 줍니다. 다른 앱을 쓰는 중에는 알림이 오지 않으니 카톡으로 "내 차례 끝!" 한마디를 😉
- **소리를 끄고 싶어요** → 홈 화면 아래나 게임 메뉴(☰)의 **소리 켜짐/꺼짐** 을 누르세요.

## 개발 메모

```
index.html  css/  js/  assets/  manifest.webmanifest   ← 게임 (정적 파일)
js/cards.js     카드 데이터 (보석 카드 67장, 왕실 카드 4장)
js/engine.js    규칙 엔진 (DOM 없음, Node에서도 동작)
js/bot.js       연습용 봇
js/net.js       온라인 동기화 (MQTT over WSS, 중계 서버 3곳)
js/app.js       화면·조작 (Node에서 불러오면 순수 도우미만 돌려줌)
tools/          PC용 정적 서버 + 인터넷 링크
tests/          node --test 테스트 (npm test, 실제 중계 서버 테스트는 npm run test:net)
docs/SPEC.md    구조·API 명세,  docs/RULES.md  규칙 정리(출처 포함)
.claude/        개발 도구 설정 (게임과 무관, 올릴 필요 없음)
```

- 테스트: `npm install` 후 `npm test`
- 디버그: 주소 끝에 `?debug=1` 을 붙이면 브라우저 콘솔에서 `window.__sd` 를 쓸 수 있어요.
- 게임 규칙 출처: Space Cowboys 공식 규칙서(2022), Dized 공식 규칙/FAQ, Board Game Arena 도움말
- 스플렌더 대결(Splendor Duel)은 Space Cowboys의 게임입니다. 이 프로젝트는 두 사람이 개인적으로 즐기기 위한 비공식 팬 제작물이에요.
